**Intro**

This project is made so all the elements are displayed correctly on popular screen sizes and verified so breaking does not occur using @media rules. It is formatted using prettier and normalize.css, The project follows a BEM file stucture (FLAT BEM) as well BEM mothodology, with hover states applied to all buttons.

**Description**

The page as a 100vh with a max-width of 1280px descendent class and the content has a padding set to 20px to keep the content from touching the edges.

The header is unrestricted.

The profile section is set up using flex box and photo cards have been set up using grid containers, and gapped according to the figma desgin.

Incorporated svg files used are symmetrical with their complementary buttons using the algin-items property.

There are a total of three @media attributes to adjust for popular screen sizing.

A decision was made in card.css ln 46 in regard to the linee-height, due to the overflow:hidden property cutting or hidding the very end of some of the card titles lettering, such as: y, g, p type letters.

Over flow is handled according to figma.
